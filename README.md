# Utomata

Utomata is an instrument for field-based computation.

This repository serves as the public hub for the project, including downloadable releases of Utomata applications and links to documentation, source libraries, examples, and related resources.

## Downloads

Current builds of Utomata are available from the [Releases](../../releases) page.

Platform support may vary between releases. See the notes attached to each release for available builds and installation information.

## Documentation

Documentation, guides, examples, and the online runner are available at:

**https://utomata.net**

## Source

Parts of the Utomata ecosystem are released as open-source libraries. Source repositories will be linked here as they become publicly available.

The desktop application itself is currently distributed as a compiled application and its source code is not part of this repository.

## Status

Utomata is under active development. Interfaces, language features, file formats, and application behaviour may change between early releases.
